# Original Boss

첫 번째 참고 이미지 `original_boss.png`의 배치에 맞춘 LDtk 레벨입니다.

## 열기

- **LDtk:** `OriginalBoss.ldtk`를 엽니다. 배경 위에 색으로 표시된 레이어를 편집할 수 있습니다.
- **Unity:** 같은 폴더의 `OriginalBoss.unity`를 엽니다. 전체 맵을 보는 카메라와 맵 오브젝트가 들어 있습니다.
- **기존 씬에 배치:** `OriginalBoss.prefab`을 드래그합니다. 원점은 이미지의 왼쪽 위이며, 맵은 오른쪽과 아래쪽으로 펼쳐집니다.
- **배치 검토:** `OriginalBoss.layout.html`을 브라우저에서 열면 원본과 충돌 영역을 겹쳐 보고 레이어를 켜고 끌 수 있습니다.

## 구성

원본 이미지 1721 × 914 px를 변경 없이 복사했습니다. 레벨은 8 px 격자에 맞춘 1728 × 920 px, Unity 배율은 32 pixels/unit입니다. 장식용 원본 타일셋이 없어서 외형은 한 장의 배경입니다. 장식 타일을 개별 편집하거나 물·조명을 애니메이션화한 맵은 아닙니다.

| 레이어 | 용도 |
| --- | --- |
| Ground | 방 바깥, 벽, 바닥. Unity Ground 레이어의 충돌체 |
| Platforms | 내부 발판. 양방향으로 충돌하는 고정 발판 |
| Climb | 사다리와 사슬 위치. 프리팹에서는 트리거 영역 |
| Water | 폭포 위치. 프리팹에서는 트리거 영역 |
| Markers | 시작점, 출구, 체크포인트 두 곳. 이름이 있는 Transform |

왼쪽 탑에서 중앙 통로로 내려오고, 오른쪽 탑과 하부 통로가 중앙 수직 통로를 통해 연결됩니다. 시작점·출구·체크포인트는 이미지에 맞춰 제안한 위치입니다. LDtk에서 이동할 수 있습니다.

이 씬은 **맵 배치용 씬**입니다. 플레이어, 적, 보스 AI, 사다리/사슬 이동, 물 효과, 체크포인트 저장 및 출구 전환 로직은 포함하지 않습니다. 프로젝트의 기존 플레이어에는 사다리 이동 구현이 없으므로 별도 연결이 필요합니다. 충돌 경계는 이미지를 보고 8 px 단위로 근사한 것입니다.

## LDtk 수정 사항 반영

LDtk Unity 패키지는 `.ldtk`를 직접 임포트하며 Ground/Platforms를 기존 `GroundTile`에 연결해 두었습니다. 별도 네이티브 프리팹·씬·검토 페이지도 함께 제공하며, 이 파일들은 자동 동기화되지 않습니다.

LDtk 파일을 저장한 뒤 프로젝트 루트에서 실행합니다:

```powershell
node Tools/BossMap/build-boss-map.cjs
```

이 명령은 `OriginalBoss.prefab`, `OriginalBoss.unity`, `OriginalBoss.layout.html`을 다시 만듭니다. 따라서 생성된 씬·프리팹을 직접 수정한 사항은 덮어씁니다. 게임 오브젝트를 추가할 때는 기존 게임 씬에 프리팹을 배치해 사용하세요. LDtk의 레이어명, 격자 크기와 레벨 크기는 내보내기 스크립트와 함께 변경해야 합니다.

## 검증 범위

레이어 정의, 셀 개수/값, 병합된 충돌 사각형의 전체 셀 일치, 시작/출구/체크포인트의 충돌체 겹침 여부를 스크립트로 확인했습니다. Unity 실행 파일을 사용할 수 없어 실제 임포트·렌더링·플레이 테스트는 수행하지 못했습니다.
