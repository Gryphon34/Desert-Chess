# UI–Map 연결 시스템 계획 (2026-10-09)

`추가 진행 상황(UI Map) 1009`에서 정리한 HUD 프리팹과 LDtk 맵을 실제 게임 흐름(GameManager → RoundManager)에 연결하는 작업입니다.

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 슬롯 구성 | 코드·기획서 기준 **무기 3칸 + 마법 3칸** (프리팹 5칸 → 6칸) |
| Level Badge | **라운드 번호** |
| 보스 라운드 | 코드대로 **6라운드에만** 등장 (회의록의 "3라운드 뒤 보스"는 잘못된 내용) |
| 라운드 전환 | 클리어 → 보상 선택 → **자동으로 다음 맵** |
| 맵 오버레이 | 우선 **진행도만** 표시 |

## 전체 흐름

```
GameManager.BeginGame / BeginPendingRound
  → StartRound(n)
      → MapManager.LoadRound(n)     해당 레벨만 켜고, 플레이어를 PlayerStart로, 카메라 범위를 맵으로
      → RoundManager.BeginRound(n)  현재 맵의 EnemySpawn / BossSpawn에서 스폰
           ├ RoundStarted(n)            → HUD: Level Badge, 진행도
           ├ KillProgressChanged(k, g)  → HUD: 처치 수
           └ RoundCleared(n)            → HUD: 진행도 → (보상 선택) → 다음 StartRound
MapManager.MapChanged(map)          → HUD: Map Title
Player.HpChanged / SlotsChanged     → HUD: 체력바, 슬롯 6칸
```

맵은 씬을 바꾸지 않고 한 씬 안에서 켜고 끕니다. LDtk 레벨이 월드 좌표에서 겹치지 않게 놓여 있고, `GameManager`가 `DontDestroyOnLoad`이며 다른 매니저를 `FindAnyObjectByType`로 찾기 때문입니다.

## 단계와 진행 상태

### 1. LDtk 데이터 — 완료
`ReferenceLayout.ldtk`에 다음을 추가했습니다.
- Level 필드: `RoundIndex`(Int), `DisplayName`(String), `IsBossRound`(Bool)
  - 1~5: `ROUND n`, 6: `BOSS` / `IsBossRound = true`
- `Entities` 레이어(그리드 8)와 Entity 정의 `PlayerStart`, `EnemySpawn`, `BossSpawn` (피벗: 아래 가운데)
- 레벨마다 PlayerStart 1개 + EnemySpawn 5개, 6번 레벨에 BossSpawn 1개
  - Ground IntGrid를 분석해 "바닥 위, 머리 위 4칸이 비어 있는 실내 칸"에 자동 배치한 위치입니다. **LDtk에서 열어 기획 의도에 맞게 옮겨주세요.**
- 텍스트(UI)는 TMP 기본 폰트에 한글 글리프가 없어 영문으로 넣었습니다.

### 2. 맵 런타임 — 완료
- `03. Map/RoundMap.cs`: LDtk 레벨의 필드·Entity를 읽어 둔 데이터(라운드 번호, 이름, 시작/스폰 지점, 월드 범위)
- `03. Map/MapManager.cs`: `LoadRound(n)`, `MapChanged` 이벤트, `ToSpawnPosition`(발밑 피벗 보정 +0.5)
- `CharacterController2D.Teleport()`: Rigidbody2D 위치·낙하 속도까지 초기화하는 순간이동
- `SimpleFollowCamera.SetBounds()` / `SnapToTarget()`: 맵 밖을 비추지 않도록 제한
  - `lerpSpeed`가 0이면(현재 Game.unity 값) 보간 없이 바로 따라가도록 바꿨습니다. 이전에는 카메라가 전혀 움직이지 않았습니다.

### 3. RoundManager / GameManager 연결 — 완료
- `RoundManager`: 맵의 EnemySpawn/BossSpawn 우선, 없으면 기존 `spawnPoints` 사용
- 이벤트 추가: `RoundStarted`, `RoundCleared`, `KillProgressChanged`
- `GameManager.StartRound()`: 맵 전환 → 스폰 순서 보장

### 4. HUD 바인딩 — 코드 완료, 프리팹 적용은 에디터 메뉴 실행 필요
- `04. UI/GameHudView.cs`: 이벤트로만 갱신(매 프레임 확인 없음)
  - 체력바: HP Fill 너비를 비율로 조절(스프라이트가 없어 fillAmount가 동작하지 않음)
  - 슬롯 6칸: 키 1~6, 라벨(무기 이름 + 남은 횟수, 주먹은 이름만), 활성 슬롯 강조
  - Level Text = 라운드 번호, Map Title = 맵 DisplayName
  - 맵 오버레이: **Tab**으로 열고 닫기, 라운드 목록(지난/현재/남은) + 처치 수
- `Player`에 `HpChanged`, `SlotsChanged` 이벤트 추가
- `CombatHud`: GameHudView가 있으면 OnGUI 체력바/슬롯은 그리지 않음(라운드 배너·게임 오버·선택 팝업은 유지)

### 5. 에디터 설정 메뉴 — Unity에서 실행 필요
`Desert Chess > UI-Map 연결 설정 (전체)` (`Editor/GameHudMapSetup.cs`)
1. Game HUD 프리팹: 슬롯 6칸으로 복제, 슬롯마다 `Label Text`, 오버레이에 `Progress Text` 추가, `GameHudView` 연결, 오버레이 기본 비활성
2. Game 씬: LDtk 맵 배치, `MapManager` 생성 및 RoundManager/GameManager/카메라 연결, 예전 테스트 바닥 `Environment` 비활성화(삭제 아님), 빌드 설정에 Game.unity 추가

여러 번 실행해도 이미 있는 것은 다시 만들지 않습니다.

### 6. 검증 체크리스트
- [ ] LDtk 재임포트 후 레벨마다 `PlayerStart`/`EnemySpawn` GameObject가 생겼는지
- [ ] 1→6라운드 진행 시 맵이 바뀌고 플레이어가 시작 지점에 서는지
- [ ] 적이 해당 맵의 EnemySpawn에서만 나오는지, 6라운드 보스가 BossSpawn에 나오는지
- [ ] 플레이어/적이 LDtk Ground(레이어 3: Ground)와 충돌하는지
- [ ] 캐릭터 크기와 맵 비율(LDtk 16 PPU)이 맞는지
- [ ] 체력·슬롯·라운드 번호가 실시간으로 바뀌는지, Tab 오버레이 진행도
- [ ] 세로로 긴 `_03` 맵에서 카메라가 맵 밖을 비추지 않는지
- [ ] 보상 팝업으로 timeScale이 0일 때도 Tab 오버레이가 열리는지
