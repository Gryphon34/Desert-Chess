## 🎮 게임 소개

> *"잡은 몬스터의 무기가 곧 나의 무기가 된다."*

데저트 체스는 **사냥 → 흡수 → 빌드 → 보스**로 이어지는 짧고 밀도 높은 런(run)을 목표로 한 플랫포머 RPG입니다.

- **🗡️ 흡수로 완성하는 빌드**<br/>
  몬스터는 저마다 무기(검, 창, 도끼, 활, 불, 물…)를 들고 있고, 처치하면 그 무기를 흡수할지 선택합니다. 화면에 보이는 몬스터의 위력이 곧 잡았을 때 얻는 무기의 위력입니다.
- **♟️ 한정된 슬롯, 전략적인 교체**<br/>
  무기 3칸 · 마법 3칸, 슬롯은 게임 내내 늘어나지 않습니다. 흡수한 무기는 **5번 쓰면 사라지기** 때문에, 무엇을 남기고 무엇을 버릴지가 매 라운드의 고민이 됩니다.
- **🔗 계열 시너지**<br/>
  같은 계열(근접 · 중병기 · 원거리 · 마법) 무기를 3개 모으면 공속 · 공격력 · 범위 보너스가 붙습니다.
- **👹 내가 만난 몬스터로 만들어지는 보스**<br/>
  6라운드 보스는 1~5라운드에서 실제로 등장했던 몬스터들의 무기 중에서 스킬 3개를 골라 사용합니다. 판마다 보스가 달라집니다.

## 🕹️ 게임 플레이 방식

### 조작키

| 키 | 동작 |
| :---: | --- |
| `A` `D` / `←` `→` | 좌우 이동 |
| `Space` | 점프 |
| `Z` | 무기 공격 — 연타 시 **3타 콤보**, 공중에서는 **점프 공격** |
| `X` | 마법 (서 있을 때만 시전) |
| `1` `2` `3` | 무기 슬롯 선택 |
| `4` `5` `6` | 마법 슬롯 선택 |
| `Tab` | 라운드 진행도 오버레이 열기 / 닫기 |

### 게임 흐름

```
게임 시작 → 라운드 입장 → 몬스터 사냥 → 처치 시 흡수 여부 선택
        ↑                                        ↓
   다음 라운드  ←  보상 선택(피 회복 / 능력 강화)  ←  20마리 처치 = 라운드 클리어

6라운드 보스 처치 → 🏆 게임 클리어      체력 0 → 💀 게임 오버
```

| 라운드 | 맵 | 등장 몬스터 | 목표 |
| :---: | --- | --- | --- |
| 1 | ROUND 1 (2048×576) | 근접 | 20마리 처치 |
| 2 | ROUND 2 (2048×1408) | 근접 + 원거리 | 20마리 처치 |
| 3 | ROUND 3 (832×1696, 세로형) | 근접 + 원거리 + 마법 | 20마리 처치 |
| 4 | ROUND 4 (2048×1152) | 근접 + 원거리 + 마법 | 20마리 처치 |
| 5 | ROUND 5 (1856×1472) | 근접 + 원거리 + 마법 | 20마리 처치 |
| 6 | **BOSS** (1600×608) | 보스 + 충전용 잡몹 | 보스 처치 |

라운드마다 맵이 바뀌며, 몬스터는 벽 · 낭떠러지를 인식하고 **위아래 층의 플레이어를 점프 / 낙하로 쫓아옵니다.**

### 무기와 마법

플레이어는 **주먹**(무제한)으로 시작합니다. 흡수한 무기는 최대 5회 사용 가능하며, 0이 되면 해당 슬롯은 주먹으로 돌아갑니다.

| 무기 | 공격력 | 공속 | 범위 | 계열 | 특징 |
| --- | :---: | :---: | :---: | :---: | --- |
| 주먹 | 1~3 | 5 | 1 | — | 기본 무기, 무제한 |
| 검 | 3~5 | 5 | 2 | 근접 | 표준형 |
| 창 | 3~4 | 6 | 3 | 근접 | 긴 사거리 |
| 도끼 | 4~7 | 3 | 2 | 근접 | 느리지만 강함 |
| 단검 | 1~3 | 8 | 1 | 근접 | 빠른 공격 |
| 망치 | 7~9 | 2 | 1 | 근접 | 가장 강하고 가장 느림 |
| 활 | 2~5 | 5 | 4 | 원거리 | 가장 긴 범위 |

| 마법 | 공격력 | 공속 | 범위 |
| --- | :---: | :---: | :---: |
| 🔥 불 | 3~6 | 4 | 3 |
| 💧 물 | 4 | 5 | 4 |
| ⚡ 전기 | 2~5 | 6 | 3 |
| 🌑 어둠 | 4~7 | 3 | 3 |

- **공속**은 공격 애니메이션 배속(공속 5 = 1.0배), **범위**는 히트박스 가로 길이(범위 1 = 1유닛)에 그대로 반영됩니다.
- **콤보 배율** — 1타 ×1.0 · 2타 ×1.5 · 3타 ×2.0 · 점프 공격 ×2.5
- 사용 횟수는 **명중이 아니라 입력 1회당 1회** 차감됩니다. (콤보 2·3타도 각각 1회)

### 몬스터 흡수와 계열 시너지

| 상황 | 선택지 |
| --- | --- |
| 빈 슬롯 있음 | **Absorb** (흡수) / **Skip** |
| 슬롯 가득 참 | **Replace 1~3** (기존 무기와 교체) / **Skip** |

흡수하지 않아도 처치 수와 라운드 진행에는 영향이 없습니다. 여러 마리를 한 번에 잡으면 하나씩 차례로 물어봅니다.

| 계열 | 조건 | 효과 |
| --- | :---: | --- |
| 근접 (Melee) | 3개 이상 | 공속 +2 |
| 중병기 (Heavy) | 3개 이상 | 공격력 +2 |
| 원거리 (Ranged) | 3개 이상 | 범위 +1 |
| 마법 (Magic) | 3개 이상 | 공격력 ×1.2 |

### 보스와 보상

| 시스템 | 내용 |
| --- | --- |
| **보스 패턴** | 3종 패턴 + 잡몹 소환. 스킬은 1~5라운드에 실제 등장한 몬스터의 무기 중에서 결정 |
| **잡몹 충전** | 보스가 소환한 잡몹을 처치하면 현재 활성 무기 · 마법 슬롯의 사용 횟수 +1 |
| **라운드 보상** | 클리어 후 **피 회복** 또는 **능력 강화**(보유 무기 공격력 · 사용 횟수 증가) 중 하나 선택 |

## 🛠️ 기술 구조

### 폴더 구조

```
Assets/
├─ 01. Script/
│  ├─ 00. Player/         플레이어 · 슬롯 · 스탯 보정 · 상태 머신(Attack/Fire/Jump…)
│  ├─ 01. Enemy/          근접 · 원거리 · 마법 몬스터, 보스 패턴
│  ├─ 02. CombatSystem/   HitBox / HurtBox, 데미지 이벤트, CombatHud
│  ├─ 03. Map/            MapManager, RoundMap (LDtk 레벨 → 라운드 맵)
│  ├─ 04. UI/             GameHudView, AbsorptionPopupView
│  └─ Editor/             UI-Map 연결 설정 메뉴
├─ 98. Tools/00. LDTK/    ReferenceLayout.ldtk (라운드 맵 6개)
├─ StreamingAssets/Table/DesertChess/
│  ├─ weapons.tsv         무기 스탯 · 계열
│  ├─ rounds.tsv          라운드별 몬스터 수 · 구성
│  ├─ rewards.tsv         보상 수치
│  └─ synergies.tsv       계열 시너지 조건 · 효과
└─ Scenes/Game.unity      통합 플레이 씬
```

### 핵심 설계

| 설계 | 설명 |
| --- | --- |
| **데이터 테이블(tsv)** | 무기 · 보상 · 라운드 · 시너지 수치를 코드가 아닌 tsv에서 관리. 몬스터 공격력도 들고 있는 무기의 tsv 수치를 그대로 사용 |
| **StatModifier** | 시너지 · 버프처럼 붙었다 떨어지는 스탯 변화를 `(기준값 + Add) × Multiply` 한 구조로 처리, Source 단위로 일괄 해제 |
| **애니메이션 기반 판정** | 타격 프레임은 코드 타이머가 아니라 애니메이션 클립이 히트박스를 켜고 끄는 방식 |
| **한 씬 맵 전환** | LDtk 레벨 6개를 한 씬에 배치하고 라운드마다 켜고 끔. `GameManager.StartRound()` → `MapManager.LoadRound()` → `RoundManager.BeginRound()` 순서 보장 |
| **이벤트 기반 HUD** | `HpChanged`, `SlotsChanged`, `RoundStarted`, `KillProgressChanged`, `MapChanged` 이벤트가 올 때만 HUD 갱신 (폴링 없음) |
| **LDtk 연동** | 레벨 필드(`RoundIndex`, `DisplayName`, `IsBossRound`)와 엔티티(`PlayerStart`, `EnemySpawn`, `BossSpawn`)를 읽어 스폰 위치 · 카메라 범위 결정 |

## 🚀 시작하기

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/Gryphon34/Desert-Chess.git
   ```
2. **Unity Hub**에서 `Unity 6000.3.15f1`로 프로젝트를 엽니다.
3. 컴파일과 `.ldtk` 임포트가 끝날 때까지 기다립니다.
4. `Assets/Scenes/Game.unity`를 열고 ▶ Play

> 맵을 수정하려면 [LDtk](https://ldtk.io/)로 `Assets/98. Tools/00. LDTK/ReferenceLayout.ldtk`를 열어 저장하면 Unity에 자동 반영됩니다. 자세한 내용은 [LDtk README](Assets/98.%20Tools/00.%20LDTK/README.md)를 참고하세요.
